# Elegance Decor - Decoration & Styling Services

A modern, fully localized (English & Arabic) project for managing and displaying decoration services and videos.

## Features
- **Multi-language Support**: Seamless toggle between English and Arabic.
- **RTL/LTR Layout**: Automatic layout direction adjustment.
- **Dynamic Content**: Localized video gallery, services, and categories managed via a backend API.
- **Responsive Design**: Optimized for desktop and mobile devices.

## Project Structure
- **/client**: React frontend (Vite, TypeScript, i18next).
- **/server**: Node.js/Express backend (TypeScript).
- **/server/data/database.json**: Simple JSON-based NoSQL database.

## Quick Start
1. Install dependencies in both `client` and `server`: `npm install`
2. Configure `.env` in the `server` folder.
3. Run `npm run dev` in both folders to start local development.

For more details, see `ADMIN_GUIDE.md` and `deployment_guide.md`.
